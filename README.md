# Contabilidad XFinity (Comcast Cable Tech)

Sistema de gestión, contabilidad y control de órdenes de trabajo para técnicos instaladores de cableado Xfinity / Comcast.

## Funcionalidades Principales
- **Registro Diario de Trabajos:** Captura rápida de órdenes de trabajo (ID de Comcast, dirección, metraje de cable, obstáculos, cliente).
- **Control Financiero & Ganancias:** Cálculo de cobros por orden, tarifas por metro/tipo de trabajo.
- **Gestión de Evidencias Fotográficas:** Almacenamiento y exportación de fotos por trabajo para compartir reportes con supervisores.
- **Cierres Semanales:** Resumen de producción semanal por ciclo de corte.
- **Seguimiento de Pagos con Retención (Holdback de 3 semanas):** Control de semanas trabajadas vs. semanas en cobro efectivo.
- **Búsqueda y Filtros:** Búsqueda rápida por fecha, ID de trabajo, dirección o estado.
